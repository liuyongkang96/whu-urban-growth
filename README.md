# 武汉城市扩张回测与可视化系统

武汉大学地理信息服务技术课程项目。用截至 2010 年的聚居地分布估计武汉中心城区样区随后五年的新增面积，再用 2015 年的遥感记录检验预测和热点排名。

## 小组开工

开发分工、数据来源、接口契约、Codex 开工任务和验收节点见 [项目实施定稿](PROJECT.md)。当前仓库提供项目计划，系统与实验结果将在开发后补充。

| 模块 | 分支 |
| --- | --- |
| A · 数据与网格 | `feat/data` |
| B · 模型与回测 | `feat/model` |
| C · 地理信息服务 | `feat/services` |
| D · 地图界面与集成 | `feat/web` |

从最新的 `main` 创建各自分支，完成一项可验证的交付后，通过 Pull Request 合并。
